# Guia de Manutenção do Perfil

## Atualizar o README

1. Edite o arquivo `README.md`
2. Faça commit e push
3. As alterações aparecem automaticamente no perfil

## Atualizar a imagem de perfil

1. Substitua o arquivo `assets/profile.png`
2. Mantenha o mesmo nome do arquivo
3. Faça commit e push

## Ativar a cobrinha de commits

1. Vá em **Settings → Actions → General**
2. Em **Workflow permissions** selecione **Read and write permissions**
3. Vá na aba **Actions**
4. Selecione o workflow **Generate Snake**
5. Clique em **Run workflow**

## Adicionar novos projetos

1. Crie o repositório do projeto
2. Atualize a tabela de projetos no `README.md`
3. Adicione o link do repositório na tabela

## Contatos

Quando criar contas no Discord ou Twitter/X, adicione os links na seção de Contato do `README.md`.
